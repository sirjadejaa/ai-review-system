# Medical Shop AI Review & Digital Customer Card System

Custom, production-grade review collection and digital customer card application built for a single independent medical shop (pharmacy).

## Key Features
- **QR-Driven Customer Landing:** Fast, mobile-first experience to give a review or view the digital card.
- **AI Review Assistant:** Non-fabricating review generation in English, Hindi, and Hinglish.
- **Digital Customer Card:** Quick one-tap Call, WhatsApp, Directions, Operating Hours, and Active Offers.
- **Owner Dashboard:** Simple, non-technical portal for reviews, private feedback, QR analytics, and store settings.
